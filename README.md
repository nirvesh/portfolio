# Personal Portfolio

My front-end portfolio — a single-page site collecting the HTML & CSS projects
I've hand-coded while learning responsive web design. Built with plain HTML and
CSS: no frameworks, no build step, no JavaScript.

## Live site

https://nirvesh.github.io/portfolio/

## What's inside

A fixed navbar, a full-height hero intro, a responsive grid of project cards
with screenshot previews, and a contact section.

### Featured projects

| Project | Description |
| --- | --- |
| Moon Orbit | A spinning Jupiter orbited by four moons across a starfield. |
| Animated Ferris Wheel | A turning Ferris wheel with swinging cabins at golden hour. |
| Newspaper Layout | A vintage front page — masthead and multi-column type. |
| City Skyline | A layered skyline that cycles from day to night. |

## Built with

- Semantic HTML5
- CSS custom properties, flexbox, and grid
- A media query for responsive layout (cards stack on narrow screens)
- No frameworks or dependencies
